# Profile visual identity

The profile connects the author's current work in systems and software with a long-term interest in computational biotechnology. The visual system uses graphite, warm ivory, and chartreuse, with editorial typography and original technical illustrations.

## Assets

- `assets/hero.png`: original conceptual artwork generated with the built-in image-generation tool. It is a visual metaphor for the transition from engineered systems to scientific exploration, not an actual molecular structure or scientific result.
- `assets/cosmos.svg`, `terraform.svg`, `nua.svg`, `discovery.svg`: original code-generated project illustrations. The diagrams are illustrative rather than measured outputs.
- `assets/method.svg` and `signature.svg`: matching vector identity elements.

All displayed assets are stored in this repository. No external badge, statistics, or typing-animation service is required. Links on the project cards open the corresponding source repositories. Text alternatives describe every linked image.

The Cosmos and Discovery SVGs contain slow, decorative SVG motion; their static artwork remains complete if animation is disabled. Reduced-motion styling hides the moving elements in renderers that support the media query.

## Maintenance

Run `python3 scripts/build_visuals.py` to rebuild the vector graphics using only the Python standard library. Edit the project descriptions in that file and keep the README text alternatives in sync. The hero is intentionally not regenerated by the script.
