## Status vocabulary
- **Planned** — no implementation claimed.
- **Started** — some effort completed; insufficient reproducible evidence.
- **Demonstrated in lab** — working, reproducible in a described lab and supported by artifacts.
- **Peer reviewed** — independent reviewer reproduced or reviewed evidence.
- **Production experience** — only if genuinely done professionally and disclosed within authorization/confidentiality bounds.

Never silently promote a project from “source authored” to “working” just because it was generated by an AI assistant. Never upload or share company/internal training data.
