# GRE General Test — graduate admission preparation

[Learning Hub](../README.md) · [Mathematics](../mathematics/README.md) · [MIS preparation](../mis/README.md) · [Study plan](ROADMAP.md) · [Progress](PROGRESS.md)

Goal: Fall 2028 graduate admission preparation. Initial target 325/340 (Quant 165, Verbal 160), Analytical Writing 4.5/6; stretch target 330. These are personal preparation goals, not admission cutoffs.

## Exam structure
| Section | Questions | Time | Score |
|---|---:|---:|---|
| Quantitative Reasoning | 27 (12 + 15) | 47 min | 130–170 |
| Verbal Reasoning | 27 (12 + 15) | 41 min | 130–170 |
| Analytical Writing | 1 Analyze an Issue essay | 30 min | 0–6 |

Total testing time 118 minutes. Quant and verbal are section-level adaptive. Recheck ETS format and school requirements before booking.

## Syllabus and learning resources
| Area | Content | Study source |
|---|---|---|
| Arithmetic | Integers, divisibility, fractions, ratios, percentages, powers, roots | [Khan arithmetic](https://www.khanacademy.org/math/arithmetic) |
| Algebra | Expressions, equations, inequalities, functions, systems, word problems | [Khan Algebra 1](https://www.khanacademy.org/math/algebra) |
| Geometry | Angles, triangles, circles, polygons, area, volume, coordinate geometry | [Khan geometry](https://www.khanacademy.org/math/geometry) |
| Data analysis | Descriptive statistics, probability, counting, tables and graphs | [Khan statistics](https://www.khanacademy.org/math/statistics-probability) |
| Verbal | Reading comprehension, text completion, sentence equivalence | [ETS preparation](https://www.ets.org/gre/test-takers/general-test/prepare.html) |
| Writing | Defensible thesis, evidence, counterarguments, clarity | [ETS test content](https://www.ets.org/gre/test-takers/general-test/prepare/content.html) |

No calculus is required for GRE Quant. Use existing mathematics track selectively, not as a separate duplicate curriculum.

## Method
Diagnose → understand → solve independently → analyze errors → retest after delay → practice under time. Never count viewing lessons as mastery. Do not upload copyrighted questions or private score reports to public GitHub.
