# Human skills — a small optional practice shelf

[← Learning Hub](../README.md) · [Learning philosophy](../LEARNING_PHILOSOPHY.md) · [Practice templates](PRACTICE_TEMPLATES.md)

**Curated 16 November 2026.** Communication, visual judgment, decision-making and entrepreneurship matter, but none requires a second weekly course schedule. This is an **optional reference shelf**, not an employment prerequisite or record of completed training.

## Choose one skill when a real problem calls for it

| Problem you face | Strong free original source | Try something observable |
|---|---|---|
| Explain a technical achievement so others understand it | [CCI — Assert Yourself](https://www.cci.health.wa.gov.au/Resources/Looking-After-Yourself/Assertiveness) and [professional communication guide](PROFESSIONAL_COMMUNICATION.md) | Present a two-minute incident explanation to a colleague |
| A visual explanation or poster is confusing | [Nielsen Norman Group — Visual Design Principles](https://www.nngroup.com/articles/principles-visual-design/) and [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) | Compare two versions of one original design |
| A product might not solve an actual customer problem | [Y Combinator Startup School](https://www.startupschool.org/) and [YC library](https://www.ycombinator.com/library) | Interview prospective users with permission, without a sales pitch |
| You need a repeatable basic marketing/sales method | [HubSpot Academy — Inbound](https://academy.hubspot.com/courses/inbound) | Test one truthful message and observe the response |
| You want face-to-face public-speaking practice | [Toastmasters — Find a Club](https://www.toastmasters.org/find-a-club) | Attend a meeting as a guest after checking location and terms |
| A consequential decision has uncertain evidence | [Decision-making guide](DECISION_MAKING.md) | Write a reversible, bounded experiment and assess the result |

## What changed

A former 12-week rotating program mixed design, styling, communication, psychology and entrepreneurship with the user's technical/German commitments. Its [old roadmap link](ROADMAP_12_WEEKS.md) now directs back to this optional menu. The source catalog has been reduced from 21 to eight strong free/mostly-free choices; the more eclectic subject guides remain as reference reading, **not** required courses.

Practice privately when examples involve personal appearance, emotions, conversations, customers or finances. This public repository should contain only approved, non-identifying examples. No personal capability or certificate is claimed until independently demonstrated.
