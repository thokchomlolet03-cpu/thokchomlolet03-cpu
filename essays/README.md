## Adding an essay later

1. Publish the piece on Medium, Substack or another public platform, then check that its **direct URL** actually opens.
2. Add a new table row above (publication date, title, direct link and a neutral category). If cross-posted, pick one primary/original link and optionally add a clearly labeled alternative.
3. Update [INDEX.csv](INDEX.csv) if maintaining the machine-readable catalog; use a stable ID so publication history can be tracked over time.
4. For analysis, separate cited facts from personal interpretation; for fiction, keep the creative-work label rather than implying an event actually happened.
5. Only share text, excerpts, images or linked sources you are authorized to publish. Never accidentally embed personal addresses, private communications or employer material.

[Copy the template](ESSAY_ENTRY_TEMPLATE.md) for the metadata and a short original introduction. **Do not add invented URLs, automatically scrape private drafts, or mark a future idea as already published.**
